# 口语化中文数字转换包 (spoken-an2cn)

一个轻量级 Python 工具包，用于**将阿拉伯数字转换为口语化的中文数字读法**。针对日常口语习惯做了优化（如"二百"→"两百"、"二万"→"两万"），支持整数、小数、负数，适用于金额朗读、数据播报、对话数据预处理等场景。

---

## ✨ 主要功能

- **口语化转换** (`An2Cn`)：将 `int` / `float` / `str` 形式的数字转为中文小写读法。
- **支持负数与小数**：如 `-3.14` → `负三点一四`。
- **自动去末尾零**：小数部分末尾的零会被去掉（`1.50` → `一点五`）。
- **口语化"两"替换**：在百、千、万、亿前（且不在"十"之后）的"二"自动替换为"两"。
- **纯标准库实现**：无任何第三方依赖。

本包为自用包，直接在源码目录下安装即可。


```bash
cd spoken_an2cn
pip install -e .
```

## 🚀 快速开始

```python
from spoken_an2cn import An2Cn

print(An2Cn(0))        # 零
print(An2Cn(10))       # 十
print(An2Cn(100))     # 一百
print(An2Cn(200))     # 两百
print(An2Cn(1234))    # 一千二百三十四
print(An2Cn(20000))   # 两万
print(An2Cn(100000))  # 十万
print(An2Cn(123456789))  # 一亿二千三百四十五万六千七百八十九
print(An2Cn(-3.14))   # 负三点一四
print(An2Cn("1.50"))  # 一点五
print(An2Cn(1.0))     # 一
```

**参数说明：**
| 参数 | 类型 | 说明 |
|------|------|------|
| `inputs` | `str` / `int` / `float` | 待转换的数字；字符串形式可避免浮点精度问题 |

**返回值：** 中文读法字符串。

## 🧠 转换逻辑详解

- **整数部分**：沿用 `cn2an` 的 low 模式算法，按"个、十、百、千、万、亿"逐位拼装，并自动整理多余的"零"（如 `10001` → `一万零一`）。
- **"一十"开头省略"一"**：如 `10` → `十`、`15` → `十五`。
- **口语化"两"替换**：对"二+（百/千/万/亿）"且前面不是"十"的位置，将"二"替换为"两"（如 `200` → `两百`、`2万` → `两万`）；但 `12` 仍读作"十二"，不动。
- **小数部分**：以"点"开头逐位读数字，并去除小数末尾无意义的零（`1.50` → `一点五`，`1.0` → `一`）。
- **负数**：以"负"开头。
- **位数上限**：整数部分最多支持 16 位（到"千亿兆"级），超出会抛出 `ValueError`。

---

## ⚠️ 异常与边界

- 输入为 `None` 或空字符串 → 抛出 `ValueError`。
- 输入包含非数字字符（除 `-` 与 `.`）→ 抛出 `ValueError`。
- 多个小数点 → 抛出 `ValueError`。
- 小数部分超过 16 位会截断并发出 `UserWarning`。
